# Условия использования Klone Launcher

**Дата вступления в силу:** 17 ноября 2026 г.
**Последнее обновление:** 17 ноября 2026 г.

Настоящие Условия использования («Условия») регулируют использование программного обеспечения **Klone Launcher** («Лаунчер», «Приложение») — программы для управления версиями Minecraft, модпаками и их запуска на персональном компьютере.

Используя Лаунчер, вы подтверждаете, что прочитали, поняли и принимаете настоящие Условия. Если вы не согласны с какими-либо положениями — пожалуйста, не используйте Лаунчер.

## 1. Описание сервиса

Klone Launcher — это локальное приложение, которое:

- устанавливает и запускает официальные версии Minecraft;
- устанавливает версии с модификациями (Fabric, Forge, NeoForge);
- устанавливает модпаки в форматах Modrinth (.mrpack) и CurseForge;
- управляет аккаунтами Minecraft через авторизацию Microsoft;
- при необходимости загружает среду выполнения Java;
- проверяет наличие новых версий Лаунчера и предлагает их установить;
- отображает статус игры в Discord (Rich Presence) — опционально.

Лаунчер **не является** сервером, магазином или коммерческим сервисом. Вся работа выполняется на вашем устройстве.

## 2. Аккаунты и авторизация

- Для запуска Minecraft требуется лицензионный аккаунт Microsoft/Minecraft. Авторизация выполняется через официальные сервисы Microsoft (login.live.com, Xbox Live, Minecraft Services). Лаунчер не предназначен для обхода проверки лицензии игры.
- Пароль от вашего аккаунта Microsoft **не передаётся и не сохраняется** Лаунчером. Авторизация происходит через официальный OAuth-флоу.
- Токены доступа хранятся **только на вашем устройстве** в локальной базе данных Лаунчера. Вы несёте ответственность за сохранность доступа к своему устройству и профилю операционной системы.
- Вы обязуетесь не использовать чужие аккаунты и соблюдать [Условия использования Minecraft](https://www.minecraft.net/en-us/usage-guidelines) и правила Microsoft.

## 4. Моды и модпаки

- Моды и модпаки создаются и распространяются третьими лицами (авторы, Modrinth, CurseForge, CurseForge CDN). Лаунчер лишь загружает и устанавливает их.

## 5. Сторонние сервисы

Лаунчер обращается к следующим сторонним сервисам для своей работы:

- **Mojang / Microsoft** — авторизация, запуск Minecraft, загрузка версий;
- **Modrinth API** — загрузка информации о модах и модпаках;
- **CurseForge / Overwolf CDN** — загрузка файлов модпаков;
- **GitHub** — проверка и загрузка обновлений Лаунчера;
- **Источники Java** (Mojang / Eclipse Adoptium) — загрузка среды выполнения Java;
- **Discord** — Rich Presence (только если функция включена).

Использование этих сервисов регулируется их собственными условиями и политиками конфиденциальности. При подключении к игровым серверам Minecraft ваш ник, UUID и IP-адрес получает оператор сервера; Лаунчер за действия серверов не отвечает.

## 6. Обновления Лаунчера и загрузка Java

- Лаунчер проверяет наличие новой версии в официальном репозитории проекта на GitHub. Если версия новее установленной, Лаунчер **предлагает** обновиться; решение принимаете вы.
- Обновления распространяются через GitHub Releases. Загружайте Лаунчер только из официального репозитория: https://github.com/DIMAPLAY1221/klone-launcher
- Если для запуска выбранной версии Minecraft нужна Java, Лаунчер может загрузить её из официальных источников. Java является продуктом третьих лиц и распространяется на условиях её правообладателей.
- Если вы не обновляетесь, уже установленная копия продолжит работать локально, но мы не гарантируем её совместимость с новыми версиями Minecraft и сервисов.
