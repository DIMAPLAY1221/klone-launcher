# Политика конфиденциальности Klone Launcher

**Дата вступления в силу:** 17 ноября 2026 г.
**Последнее обновление:** 17 ноября 2026 г.

Настоящая Политика конфиденциальности описывает, как **Klone Launcher** («Лаунчер», «Приложение») обращается с информацией при его использовании на вашем устройстве.

## 1. Общий принцип

Klone Launcher — **локальное приложение**. У нас нет собственных серверов, баз данных и системы аналитики. Мы **не собираем и не храним** данные о вас на своих серверах — их просто не существует. Запросы к сторонним сервисам (см. раздел 3) выполняются напрямую с вашего устройства.

## 2. Какие данные хранятся на вашем устройстве

Лаунчер сохраняет на вашем компьютере только те данные, которые необходимы для его работы:

- **Данные аккаунтов Minecraft** — ник, UUID и токены доступа, полученные через авторизацию Microsoft. Хранятся в локальной базе данных (`%APPDATA%\.klone` / `~/.klone` и аналогичные каталоги).
- **Настройки Лаунчера** — путь к игре, выделенная память, параметры запуска и т.п.
- **Локальные логи** — история запусков и сообщений об ошибках, хранится на устройстве.
- **Установленные версии, модпаки и Java** — файлы игры в стандартном каталоге `.minecraft`, папке модпаков и каталоге Лаунчера.

Эти данные используются исключительно для работы Лаунчера и **не покидают ваше устройство** (за исключением сетевых запросов, описанных ниже).

## 3. Сетевые запросы к третьим лицам

Для выполнения своих функций Лаунчер обращается к сторонним сервисам. Эти сервисы обрабатывают данные по своим собственным политикам и, как любой сетевой сервис, видят ваш IP-адрес.

| Сервис | Для чего используется | Что передаётся |
|---|---|---|
| Microsoft / Mojang (login.live.com, xboxlive.com, minecraftservices.com, piston-meta.mojang.com, libraries.minecraft.net) | Авторизация, профиль, загрузка версий Minecraft | Токены авторизации, запросы на скачивание файлов |
| Modrinth API (api.modrinth.com) | Скачивание модпаков и информации о них | Поисковые запросы, идентификаторы проектов |
| CurseForge / Overwolf CDN | Скачивание файлов модпаков | Запросы на загрузку файлов |
| GitHub (github.com, api.github.com) | Проверка и загрузка обновлений Лаунчера | Запросы на получение информации о релизах и файлов релиза |
| Источники Java (Mojang, Eclipse Adoptium) | Загрузка среды выполнения Java | Запросы на загрузку файлов |
| Discord (локальный IPC-канал) | Rich Presence — отображение статуса игры | Имя приложения, описание «В лаунчере» / «В игре», имя запущенной версии |

Мы **не передаём** сторонним сервисам ваши персональные данные сверх того, что необходимо для выполнения соответствующего запроса.

При подключении к игровым серверам Minecraft ваш ник, UUID и IP-адрес получает оператор сервера. Лаунчер не контролирует, как серверы обрабатывают эти данные.

## 4. Локальный сервер Лаунчера

Для работы интерфейса Лаунчер запускает внутренний сервер, доступный только на вашем компьютере (`127.0.0.1`). Он не принимает подключения из сети.

## 5. Discord Rich Presence

Если функция Discord RPC включена в настройках, Лаунчер сообщает локальному клиенту Discord следующие сведения:

- название приложения («Klone Launcher»);
- текст статуса («В лаунчере», «Запуск игры», «В игре»);
- идентификатор запускаемой версии Minecraft;
- время начала сессии.

Эти данные видны только участникам ваших Discord-серверов и в вашем профиле Discord. Вы можете отключить функцию в настройках Лаунчера.

## 6. Чего мы НЕ делаем

- Не собираем аналитику, телеметрию и статистику использования;
- Не показываем рекламу и не используем рекламные SDK;
- Не используем файлы cookie;
- Не передаём данные третьим лицам для маркетинга;
- Не требуем регистрации на собственных серверах.

## 7. Хранение и защита данных

- Все данные хранятся только на вашем устройстве.
- Токены доступа хранятся в локальной базе данных Лаунчера. Любой, кто получит доступ к вашему профилю ОС или каталогу `.klone`, сможет использовать эти токены, поэтому не передавайте такой доступ другим лицам.
- Логи могут содержать пути к файлам (в том числе имя пользователя ОС). Проверяйте логи перед публикацией, например, в GitHub Issues, и никогда не публикуйте токены.
- Вы можете в любой момент удалить аккаунт и все данные, удалив Лаунчер и каталоги `%APPDATA%\.klone`, `~/.klone` и `.minecraft`.

## 8. Ваши права

Поскольку мы не получаем и не храним ваши данные, запросы на доступ, исправление или удаление данных к нам не применимы: вы полностью управляете данными самостоятельно на своём устройстве. Для данных, обрабатываемых сторонними сервисами (Microsoft, Modrinth, GitHub и др.), обращайтесь непосредственно к ним.

## 9. Дети

Лаунчер не предназначен для детей и не собирает персональные данные несовершеннолетних. Использование Minecraft несовершеннолетними регулируется правилами Microsoft.
